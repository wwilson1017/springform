## With a password

Enter your email and password on the sign-in page. After several wrong attempts the page makes you wait before trying again; that protects your account from guessing.

Forgot your password? Ask an admin for a reset link, or use the reset option on the sign-in page if your install sends email.

You stay signed in for about 12 hours, then sign in again.

## Add an authenticator app

An authenticator app (such as Google Authenticator, 1Password or Authy) adds a six-digit code to every sign-in, so a stolen password is not enough.

1. Go to **Settings → Account** and, in the **Security** card, choose **Set up two-factor**.
2. Scan the code with your app and type the six digits it shows.
3. Save the backup codes somewhere safe. Each one works once if you lose your phone.

You can tell a computer you trust to skip the code for a while.

## With Google

If an admin has set up Google sign-in, the sign-in page shows a **Continue with Google** button. You still need an invite: Google sign-in never creates an account by itself.

- Gmail addresses and company Google Workspace addresses are linked to your account the first time you use the button.
- Any other address must be linked from inside the app first: sign in with your password, then use **Link Google** in the **Security** card of **Settings → Account**.

Google sign-in skips the authenticator code unless an admin turns on "Ask for the two-factor code after Google too" in **Settings → Sign-in**.
